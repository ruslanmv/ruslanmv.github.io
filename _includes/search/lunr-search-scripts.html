It is now fetched the first time the reader shows intent to search — hovering, focusing or activating the search toggle — which keeps it off the initial load of every page while still being ready by the time the search panel is usable. Order matters: lunr.min.js defines `lunr`, lunr-store.js defines `store`, and lunr-.js builds the index from both, so they are chained rather than loaded in parallel. {%- endcomment -%}
