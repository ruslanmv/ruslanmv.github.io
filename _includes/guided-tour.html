{%- comment -%} Guided tour — a narrated page that scrolls itself. One click plays the whole narration; the page follows the audio, section by section, using the chapter marks recorded at synthesis time (`chapters` in _data/audio_manifest.json). Playback UI states (never two at once): idle large "Start the guided tour" control, no player playing-collapsed compact mini-player, bottom-right <- the normal state playing-expanded full transport, only after the reader expands it paused-collapsed same mini-player, play icon closed no player; a quiet "Resume guided tour" if there is progress Collapse and close are different actions: collapse keeps the narration running, close stops it. The mini-player is the default once narration begins — the full bar is never persistent. Text is rationed by state. Collapsed the player carries only its position in the tour and the clock; the chapter name appears when it is expanded. The chapter list is likewise a drawer, not a column: closed it is a hairline and one violet dot at the right edge, and it opens only when the reader asks (the rail's chevron, or the chapter button in the full transport). Chapter changes are always announced to assistive tech, whatever is on screen. Contract -------- * the manifest entry needs `chapters: [{ id, title, start }]` — produced by markers in the narration source * every chapter id must match a `data-tour-chapter=""` element on the page (a missing one is reported in the console, never to the reader) Degrades in this order: no chapters -> plain narration player; no JS -> a native
